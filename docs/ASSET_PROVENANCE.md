# DAVID asset provenance

## Current v0.3 (generated locally)
All the modeled architecture, carpets/rugs/wood/marble/leather maps, instrument silhouette geometry, sofas, display niches and glass cases are authored procedurally by `build_gallery_v03.py` in the downloadable development-source archive. The approved concept images are **not** loaded as billboards, floor textures, or decorative pictures.

No third-party instrument GLB files or trademarked product logos have been embedded in the current scene. Only assigned real database showroom products display brand/price/stock.

## Requirements
Maintain a manifest per imported asset with author/source URL/license/date/version/triangle count/scale and exact binary checksum. Use correct brand assets only when backed by actual store catalog content and permission. Photorealism must be measured against approved reference-room views, and FPS measured in a real browser.
