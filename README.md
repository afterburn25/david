# Prof Erny's Music — DAVID
Source of truth for the luxury navigable 3D music store (PHP/MySQL shared-hosted commerce + Three.js GLB showroom).

**Approved vision:** walk *inside* photorealistic luxury room designs. Images are reference, never 2D backdrops. Build real 3D meshes, interiors, carpeting, brass-trim display cabinetry, lighting, furnishings and recognizable instruments.

Read PROJECT_STATUS.md and SESSION_HANDOFF.md before working. Do not claim 60 FPS or photorealistic fidelity until benchmarked / visually checked. Preserve existing installation; do not overwrite config, data, or re-run installer during upgrades.
